# Video Files Directory

This directory should contain the IPL team highlight videos:

- `csk.mp4` - Chennai Super Kings highlights
- `rcb.mp4` - Royal Challengers Bangalore highlights  
- `mi.mp4` - Mumbai Indians highlights

## Note
Video files are not included in the repository due to their large size. 
The video component will gracefully handle missing files and show placeholder content.

## For Development
Place your video files in this directory to test the video functionality locally.
